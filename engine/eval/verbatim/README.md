# 不翻译片段评测集 verbatim_v1（#101）

检查翻译时代码、标识符、路径等是否原样保留，以及标点密集的自然句有没有被误伤。评测脚本
`scripts/eval_verbatim.py`，规则与结果见 [docs/engine/不翻译片段.md](../../../docs/engine/不翻译片段.md)。

## 来源与许可证

169 条全部由本项目成员为 #101 **自行编写**，没有摘抄第三方文档、代码或语料。其中的包名（如
`com.tencent.mm`）、命令（`kubectl`、`docker`）、类名（`java.lang.NullPointerException`）等只是
公开的标识符，用作测试输入。随仓库以 MIT 许可证发布。生成与校对用的草稿脚本没有入库，
数据以本 jsonl 为准。

## 字段

| 字段 | 说明 |
| --- | --- |
| `id` | `<方向>-<类别>-<序号>`，唯一 |
| `category` | 类别，见下表 |
| `src` / `tgt` | 方向，`en→zh` 92 条，`zh→en` 77 条 |
| `text` | 原文 |
| `keep` | 要逐字保留的片段；译文里出现次数不少于原文才算保留 |
| `verbatim` | 为 `true` 时整段都是代码 / 标识符，译文必须与原文逐字相同且 `route` 为空（没经过模型） |
| `ref` | 只有 `punct` 类有：人工参考译文，用来算 chrF |

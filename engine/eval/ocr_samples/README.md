# OCR 评测样例集（#54）

32 张固定样例，给 `scripts/eval_ocr.py` 用。说明与结果见 [docs/engine/OCR评测.md](../../../docs/engine/OCR评测.md)。

## 来源与许可

| 项 | 说明 |
|---|---|
| 文字 | 全部原创（界面文案、说明文、代码片段均为本项目自拟），不摘录任何网站或书籍 |
| 渲染 | `scripts/make_ocr_samples.py` 用 Pillow 渲染，固定画布，无随机数，可重复生成 |
| 字体 | Noto Sans CJK / Noto Serif CJK（SIL OFL 1.1）、DejaVu Sans Mono（Bitstream Vera 许可）。字体只用于渲染，未随样例分发；OFL 与 Vera 许可都不约束渲染出的图片 |
| 样例许可 | **CC0-1.0**（每条样例在 `samples.json` 的 `source` / `license` 字段里也有记录） |
| 体积 | PNG 合计约 1.5 MB（单张 ≤ 190 KB），随仓库提交；评测不需要重新生成 |

## 标注约定（`samples.json`）

- `paragraphs`：期望段落，**顺序即阅读顺序**（双栏先左栏后右栏；竖排从右到左）。
- UI 的菜单项、状态栏字段、按钮、对话框的每一行各自是一段——即使行距和正文一样。
  这正是评测「UI 小字被误合并」要看的地方：合并后翻译会把几条互不相关的短句连成一句。
- 代码：每个非空行一段（不希望翻译时把两行代码连起来）。
- 正文段内换行不算段落边界；段首缩进或段间空行才算。
- 竖排用竖排标点字形渲染（`︒`、`︑`、`﹁﹂` 等），期望文本写常规标点，评测时 NFKC 归一后比较。

## 重新生成

需要 Linux 上的 `fonts-noto-cjk` 与 `fonts-dejavu`，以及 Pillow：

```bash
python scripts/make_ocr_samples.py
```

改动样例后需同时提交图片与 `samples.json`，并在 PR 里注明（历史评测数据与新样例不可直接比较）。

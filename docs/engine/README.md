# 引擎文档

本目录存放翻译服务的设计与交付说明，与 [docs/research/](../research/) 里的调研分开：

- 引擎设计与模块边界
- 本机 HTTP API
- 模型选型、许可证与「不采用」清单
- [模型目录约定](模型目录约定.md)：CTranslate2 输出目录、元数据与转换命令
- 随安装包分发的第三方模型署名

模型权重不进 git。新增模型必须在这里登记许可证后才能进入下载或打包流程。**不得默认打包 CC BY-NC 等非商用权重**（如 NLLB 官方权重）。

具体文档由后续 Issue 加在本目录。规格仍以 [MVP 范围冻结](../research/MVP范围冻结-v0.1.md) 和 [引擎验收标准](../research/引擎验收标准-v0.1.md) 为准。

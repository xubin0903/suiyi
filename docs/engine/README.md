# 引擎文档

本目录存放翻译服务的设计与交付说明，与 [docs/research/](../research/) 里的调研分开：

- 引擎设计与模块边界
- 本机 HTTP API
- 模型选型、许可证与「不采用」清单
- [模型目录约定](模型目录约定.md)：CTranslate2 输出目录、元数据与转换命令
- [语种检测](语种检测.md)：离线检测方案、许可证、体积与实测性能
- 随安装包分发的第三方模型署名

模型权重不进 git。新增模型必须在这里登记许可证后才能进入下载或打包流程。**不得默认打包 CC BY-NC 等非商用权重**（如 NLLB 官方权重）。

已有文档：

- [分句规则](分句规则.md)：中英日规则分句、OCR 断行与译文拼回
- [翻译核心](翻译核心.md)：引擎适配层、CTranslate2 后端、语种对路由与英文中转
- [HTTP API](HTTP-API.md)：本机回环上的 `/health`、`/languages`、`/translate`

后续 Issue 继续把设计说明加在本目录。规格仍以 [MVP 范围冻结](../research/MVP范围冻结-v0.1.md) 和 [引擎验收标准](../research/引擎验收标准-v0.1.md) 为准。

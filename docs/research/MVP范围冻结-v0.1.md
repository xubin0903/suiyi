# 随译 · MVP 范围冻结 v0.1

> 冻结日：2026-09-20  
> 状态：产品负责人草案，待用户确认仓库名与许可证后执行建仓

## 已定事实
- 开源、免费、轻快；核心引擎一套 + 各端薄适配
- 工作流：剪贴板复制译 + 快捷键裁剪 OCR 译
- 引擎：本地轻量开源 NMT（工程先 CT2/OPUS）；自研 Context Layer（切分/术语/一致）；**本期不考虑 LLM（含桌面可选）**
- 一期客户端：**Windows**
- 语种：常见语种可按需下载；中英日必测；中文效果优先

## MVP 做
1. Win 托盘/常驻：全局热键、剪贴板监听（可配置是否自动译）
2. 裁剪框选 → OCR → 译 → 结果窗
3. 本地引擎服务（CT2/OPUS）+ 引擎适配层
4. Context Layer P0：切分 + 本篇术语表 + 专名一致（不做 LLM）
5. 模型按需下载（至少中英日相关包可装）
6. README / LICENSE / 基础 CI（lint/build 骨架）
7. 开源仓库公开（或先 private 再公开，建仓时定）

## MVP 不做
- 安卓 / iOS / 鸿蒙客户端
- 商业云 API / BYOK 主路径
- 任何 LLM 路径
- IME、视频字幕、无障碍读屏
- 像素级多端一致、账号体系、付费

## 仓库与许可证建议
- 仓库名建议：`suiyi`（中文名随译）；owner：`xubin0903`（与现有 GitHub 账号一致）
- 应用代码建议：**MIT** 或 **Apache-2.0**（宽松、利于贡献）
- 模型权重：**不进主仓大文件**；用下载清单 + 各模型原许可证（OPUS 多为 CC BY；勿默认打入 NC 权重）
- 文档与样例：与主仓同许可或 CC BY 4.0

## 标准开发流程（GitHub）
1. `main` 保护；功能分支 → PR → Review → 合并
2. Issue 管需求/缺陷；里程碑绑 MVP
3. PR 模板 + 简单 CI
4. 云端 Coding Agent 只经 PR 改代码；负责人审范围与验收

## 演示过关标准（Win）
- 复制一段中/英/日文本能出译文
- 热键框选屏幕文字经 OCR 能出译文
- 无网（模型已缓存）可译
- 关闭一切「高级/可选」后仍完整可用（无 LLM）

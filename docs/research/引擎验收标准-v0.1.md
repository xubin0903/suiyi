# 随译 · 引擎验收标准 v0.1

> 拍板日：2026-09-20  
> 已定：默认轻量 NMT + 自研 Context Layer；本地 LLM 仅桌面可选。

## A. 架构
- 默认路径：本地轻量 NMT，无云、无强制 LLM
- 必须有可替换的引擎适配层（先 CT2/OPUS，后可换 Bergamot 系等）
- Context Layer 与具体 NMT 解耦
- 桌面 LLM：可选插件；关闭时产品完整可用

## B. 语种
- MVP 必测：中↔英、中↔日、英↔日
- 常见语种：至少再覆盖韩/法/德/西/俄中的多数（可按需下载）
- 未下载语向须明确提示

## C. 中文效果（优先）
- 固定中文样例集（短句、口语、专名、轻微 OCR 噪声）
- 中→外、外→中人工可读、专名不乱翻
- Context Layer 中文分句/专名有单独用例

## D. 上下文层
- P0：切分 + 本篇术语表 + 译后专名一致
- P1：会话记忆（用户改译写回）
- P2：滑动窗口 / 两遍译（可开关）
- 长文开启上下文层后专名一致率高于纯句级基线（测法待定）

## E. 体验与部署
- 复制翻译与快捷键裁剪共用同一引擎服务
- Win 桌面本地服务；模型按需下载
- 手机：NMT+上下文层；不要求 LLM

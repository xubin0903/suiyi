# M4：Windows 便携包（第一刀）

面向 v0.1 发布的**便携 zip**：解压后运行 `Suiyi.exe`，由客户端拉起同目录下的打包引擎。托盘与进程监管沿用现有实现，不重做。模型与 OCR **不**打进包，按需下载（见 [模型目录约定](../engine/模型目录约定.md)）。

相关 Issue：#127（骨架）、#130 / #131（引擎 exe）、#132（CI 拼入引擎）、#135（按需下载）。

## 目录布局

```
Suiyi/                              # 解压根 = 客户端 BaseDirectory
  Suiyi.exe                         # dotnet publish 产物
  *.dll / runtimes/ …
  engine/
    suiyi-engine.exe                # 引擎 PyInstaller onedir 入口（CI 制品已含）
    _internal/ …                    # onedir 依赖（若采用 onedir）
    README.txt                      # 无 exe 时的说明
  models/
    README.txt                      # 空目录说明；实际权重按需放入
  settings.portable.example.json    # 示例：相对路径指向引擎与 models
```

设置文件默认仍是 `%APPDATA%\suiyi\settings.json`。便携调试可设：

```powershell
$env:SUIYI_CONFIG_DIR = "D:\Suiyi\config"
$env:SUIYI_LOG_DIR = "D:\Suiyi\logs"
```

## 启动引擎的方式

`EngineCommandResolver` 优先级（命中即用）：

1. 设置 `engine.command` + `engine.args`（相对路径相对 **Suiyi.exe 所在目录**）
2. 同目录下存在 `engine\suiyi-engine.exe` 时自动使用（无需改设置）
3. `engine.pythonPath` → 仓库 `.venv` → `py -3.11` / PATH 上的 `python`（开发态）

实际参数一律追加：

```text
serve --port <port> --preload <preload> [--preload-ocr] [--models-dir <dir>]
```

与开发态 `python -m suiyi_engine serve …` 同一套 CLI。因此打包后的 `suiyi-engine.exe` 必须接受相同的 `serve` 子命令。

### 示例 settings（便携）

把 `client/packaging/settings.portable.example.json` 里 `engine` 段合并进设置，或整份作参考：

```json
"engine": {
  "port": 18780,
  "command": "engine\\suiyi-engine.exe",
  "args": null,
  "modelsDir": "models",
  "preload": "zh-en,en-zh",
  "preloadOcr": true
}
```

未写 `command`、但包内已有 `engine\suiyi-engine.exe` 时，客户端也会自动发现。开发树里没有该文件时行为与 M3 相同（走 Python）。

## 如何 publish 客户端

在仓库根目录。需要 [.NET 8 SDK](https://dotnet.microsoft.com/download)；目标机器若用框架依赖发布，还需 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)。

### 框架依赖（CI 默认，体积小）

```powershell
# Windows PowerShell
.\client\packaging\publish-portable.ps1 -OutputDir .\artifacts\suiyi-portable
```

```bash
# bash（Linux 上 EnableWindowsTargeting 可产出 win-x64 文件，不能本机运行）
./client/packaging/publish-portable.sh ./artifacts/suiyi-portable
```

等价手动命令：

```bash
dotnet publish client/src/Suiyi.App/Suiyi.App.csproj -c Release -r win-x64 --self-contained false \
  -o ./artifacts/suiyi-portable
mkdir -p ./artifacts/suiyi-portable/engine ./artifacts/suiyi-portable/models
cp client/packaging/engine/README.txt ./artifacts/suiyi-portable/engine/
cp client/packaging/models/README.txt ./artifacts/suiyi-portable/models/
cp client/packaging/settings.portable.example.json ./artifacts/suiyi-portable/
```

### 自包含（用户机可不装 .NET Runtime）

```powershell
.\client\packaging\publish-portable.ps1 -OutputDir .\artifacts\suiyi-portable -SelfContained
```

### 拼入引擎 onedir（本机）

```powershell
.\client\packaging\bundle-engine.ps1 -PortableDir .\artifacts\suiyi-portable `
  -EngineOnedir .\artifacts\suiyi-engine-win-x64\dist\suiyi-engine
```

```bash
./client/packaging/bundle-engine.sh ./artifacts/suiyi-portable \
  ./artifacts/suiyi-engine-win-x64/dist/suiyi-engine
```

## 引擎 exe

构建步骤与产物布局见 **[Windows 打包](../engine/Windows打包.md)**（#130）。约定摘要：

| 项 | 约定 |
|----|------|
| 工具 | PyInstaller **onedir** |
| 文件名 | `suiyi-engine.exe`，放在便携根的 `engine\`（连同 `_internal\`） |
| CLI | 与 `python -m suiyi_engine` 相同：`suiyi-engine.exe serve --port 18780 …` |
| 依赖 | 不得带 torch/transformers；ctranslate2 原生库打进 onedir |
| 模型 | **不**打进包；读 `--models-dir` 或便携根下 `models/` |
| 工作目录 | 客户端在无仓库根时用解压根作 WorkingDirectory |

冒烟（Windows，引擎产物就位后）：

```powershell
.\engine\suiyi-engine.exe serve --port 18780
# 另开终端
Invoke-RestMethod http://127.0.0.1:18780/health
```

客户端联调：CI 制品已含引擎；本机可先 `publish-portable` 再 `bundle-engine` 拼入 onedir，启动 `Suiyi.exe`，托盘应进入就绪（可先不预加载模型，或按文档转换 mvp 模型到 `models\`）。

## 模型 / OCR 按需下载（#135）

- **不要**把权重打进安装包或 zip（[CONTRIBUTING](../../CONTRIBUTING.md)）。
- 布局与开发态相同，见 [模型目录约定](../engine/模型目录约定.md)。
- 客户端默认实现为 `CatalogModelProvisioner`（`StubModelProvisioner` 仅测试/显式切换）：
  - **托盘 →「准备模型…」**：下载默认中英翻译（`opus-mt-zh-en` + `opus-mt-en-zh`）与推荐 OCR 到 `models\`。
  - 翻译权重：从与随译 int8 转换**字节一致**的 Hugging Face 仓库按文件拉取，再写入 `suiyi-model.json`（目录见 `client/src/Suiyi.Core/Packaging/model_provision_catalog.json`）。
  - OCR：从 ModelScope RapidOCR 官方 URL 拉取并校验 sha256（逻辑对齐 `scripts/download_ocr_models.py`）。
  - 开发树中若请求目录未收录的模型 id，可回退调用 `scripts/convert_models.py`（需本机 Python + `engine[convert]`）。
- 默认中英集用 bundled 级 `opus-mt-en-zh`（约 84 MB），**不是** mvp 主模型 `opus-mt-eng-zho-tc-big-2022-05-14`（约 238 MB）。引擎在仅装 bundled 时仍可走 en→zh，并告警缺主模型；要主模型请在开发树执行 `python scripts/convert_models.py --ids opus-mt-eng-zho-tc-big-2022-05-14`。
- 浮窗「未安装语向模型 / OCR 模型未安装」会提示点托盘「准备模型…」。仍可用脚本：

```powershell
python scripts\convert_models.py --tier mvp --out-dir D:\Suiyi\models
python scripts\download_ocr_models.py --models-dir D:\Suiyi\models
```

## CI 制品

`.github/workflows/ci.yml` 在 Windows 上分两步产出最终便携包（#132）：

1. **client**：`dotnet publish`（win-x64，框架依赖）→ 中间制品 `suiyi-portable-client-win-x64`（仅骨架）
2. **拼便携包**：下载骨架 + 同次 workflow 的 `suiyi-engine-win-x64` onedir（若本次未跑 engine job 则在拼包机上补打）→ 拷入 `engine\` → 验收 `engine\suiyi-engine.exe`、`_internal\`，并跑 `--version` / `serve --help`
3. 上传最终制品 **`suiyi-portable-win-x64`**（Actions 再打成 zip 供下载）

| 制品 | 内容 |
|------|------|
| `suiyi-portable-win-x64` | 客户端 + **已拼入的** `engine\suiyi-engine.exe` + `_internal\`；`models\` 仅占位 README（无按需下载的翻译/OCR 权重；`_internal` 内可能含 rapidocr wheel 自带的小 ONNX，与引擎制品 #131 一致） |
| `suiyi-engine-win-x64` | 引擎 onedir（可单独调试，可选） |

**仍不含**翻译 / OCR 模型权重。解压后需自行准备模型（见下节），再启动 `Suiyi.exe`。

### 解压试用（Windows）

1. 从 Actions 下载 `suiyi-portable-win-x64`，解压到任意目录（如 `D:\Suiyi`）
2. 确认存在 `Suiyi.exe`、`engine\suiyi-engine.exe`、`engine\_internal\`
3. （可选）把示例设置合并进 `%APPDATA%\suiyi\settings.json`，或设 `SUIYI_CONFIG_DIR` 指向解压目录下的配置夹
4. 按 [模型目录约定](../engine/模型目录约定.md) 转换 / 下载权重到解压根的 `models\`（或设置里的 `engine.modelsDir`）
5. 安装 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)（框架依赖发布）后双击 `Suiyi.exe`

本机拼包（不经过 CI）示例：

```powershell
.\client\packaging\publish-portable.ps1 -OutputDir .\artifacts\suiyi-portable
.\engine\packaging\build_windows.ps1 -OutputDir .\artifacts\suiyi-engine-win-x64
.\client\packaging\bundle-engine.ps1 -PortableDir .\artifacts\suiyi-portable `
  -EngineOnedir .\artifacts\suiyi-engine-win-x64\dist\suiyi-engine
```

## Windows 实机补测清单（合入后人工）

1. 解压 CI artifact `suiyi-portable-win-x64`，确认已有 `engine\suiyi-engine.exe` 与 `_internal\`（无需再手动拷引擎）
2. 启动客户端，确认自动发现或 `engine.command` 生效，托盘进入就绪（模型可先不装）
3. `models` 为空时文本翻译应提示缺模型；托盘「准备模型…」后默认中英 + OCR 就绪，预加载成功（主模型 big en→zh 可选）
4. 杀客户端进程后引擎随 Job Object 退出
5. 开发态（仓库树、无 `engine\suiyi-engine.exe`）仍走 `.venv` / `python -m`，回归 M3 路径
